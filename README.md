# MindMitra

**Your quiet daily companion for stress, loneliness, and tough days.**

MindMitra is an in-development AI/ML-track hackathon prototype by Team TriNova for Kritical Hacks '26. It aims to offer voluntary daily check-ins, non-diagnostic mood trends, gentle suggestions, and access to current support resources.

## Planned demo workflow
1. Enter a journal check-in and optionally choose mood, sleep, and energy.
2. Review a day/week mood trend.
3. Receive supportive, non-diagnostic suggestions.
4. Request up-to-date support resources through a backend TinyFish integration.

## Stack
- React frontend (planned)
- Python FastAPI backend (planned)
- TinyFish integration (planned; **not implemented yet**)

## Privacy and safety
- Never send journal or voice content to TinyFish; only minimal search context such as city and exam name where needed.
- Never commit API keys, secrets, or private check-ins.
- Mood insights are not diagnoses or emergency monitoring.
- Display source links for support resources; do not label information verified without checking an authoritative source.
